# Third-party notices

PrintBridge installers contain the .NET Windows Desktop runtime and Microsoft.Extensions dependencies. The build collects their license and notice files into the installed ThirdParty directory. The installer is built with [Inno Setup](https://jrsoftware.org/isinfo.php) by Jordan Russell and Martijn Laan. Inno Setup and the Microsoft components retain their own license terms.

The EXE setup uses bundled Inno Setup translations and includes the Simplified Chinese and Serbian (Cyrillic) translations from [Inno Setup source](https://github.com/jrsoftware/issrc/tree/09e42ff22c97d1770a5a65b2e2ba7f086a2b5b0d/Files/Languages), distributed under the [Inno Setup License](installer/Languages/LICENSE-Inno-Setup.txt).
