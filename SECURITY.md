# Security

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/develmax/PrintBridge/security/advisories/new). If the form is unavailable, contact the maintainer before sharing technical details publicly. Include the affected version, impact, and relevant diagnostic details with private data removed.

PrintBridge binds its listener to IPv4 loopback and uses Windows elevation for print queue changes. Keep the installed application and the Windows printer driver current.
